# Unmaintained Calculators

Mature applications that are still reachable or usable but no longer actively maintained.

- [calc](https://github.com/alfredxing/calc) - An interactive expression calculator for the terminal, with history and constants. `Windows` `macOS` `Linux` `CLI` · **Price:** Free · **License:** MIT · **Source:** [GitHub](https://github.com/alfredxing/calc) · ⚠️ **Unmaintained:** Repository archived in 2021.
- [Galculator](https://github.com/galculator/galculator) - A compact GTK scientific calculator with algebraic, RPN, formula-entry, and paper modes. `Linux` · **Price:** Free · **License:** GPL-2.0-or-later · **Source:** [GitHub](https://github.com/galculator/galculator) · ⚠️ **Unmaintained:** Last tagged release (v2.1.4) in 2015.
- [GraphCalc Desktop](https://www.graphcalc.com/) - The original desktop application, which plots 2D and 3D equations and performs scientific calculations. `Windows` `Linux` · **Price:** Free · **License:** GPL-2.0-only · **Source:** [SourceForge](https://sourceforge.net/projects/gcalc/) · ⚠️ **Unmaintained:** Last desktop release in 2003; the website now focuses on online calculator pages.
- [mdlt](https://github.com/metadelta/mdlt) - Performs arithmetic, derivatives, integrals, and other symbolic operations from the terminal. `Windows` `macOS` `Linux` `CLI` · **Price:** Free · **License:** GPL-3.0-or-later · **Source:** [GitHub](https://github.com/metadelta/mdlt) · ⚠️ **Unmaintained:** Last release in 2017.
- [NoteCalc](https://bbodi.github.io/notecalc3/) - Combines variables, units, conversions, comments, and line references in a browser calculation notepad. `Web` · **Price:** Free · **License:** AGPL-3.0-only · **Source:** [GitHub](https://github.com/bbodi/notecalc3) · ⚠️ **Unmaintained:** Last tagged release in 2024.
