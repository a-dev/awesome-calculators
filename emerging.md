# Emerging calculators

These calculators have passed basic checks of representative calculations and their explanations, but we need more evidence before recommending them on the [main list](README.md). These checks are not a full validation, and placement here does not imply poor quality.

Moving to the main list requires a credible independent review or use case, or a thorough maintainer assessment covering representative calculations, edge cases, and documented methods or assumptions. There is no minimum age or automatic promotion. Please keep application-specific review notes in pull request discussions or closing comments.

We prefer open-source calculators because anyone can inspect their code and verify how they calculate results.

You're welcome to suggest a calculator or request a placement review by following the [contribution guidelines](contributing.md). We keep the same categories as the main list, even when they have no entries here.
